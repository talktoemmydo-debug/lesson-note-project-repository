# Start here — read this before anything else

**What this project is.** Lesson notes and end-of-term practice papers for **Mercy Model Schools**, built
from the NERDC 2025 scheme. One book per class per term — `notes/<Class> - <Term>.docx` — carrying every
note that class is taught in the term plus one subject paper per subject, at reading level, with **no
answer key and no grown-up-facing text anywhere in the pupil book**. Everything is generated from sources
by the scripts in `tools/`, so a text change is re-rendered, never hand-patched into a book.

**This project runs as a loop now — read `80-AUTOLOOP.md` first.**  Work advances every turn with no
review in between, on the owner's instruction of 2 Sep 2026.  A turn is closed by one command,
`python3 tools/gates.py --class "Nursery 2" --term "3rd Term"`, which runs the ten gates in order of
cheapness and ends `ALL CLEAR`.

Both finished books have `.md` and `.docx` twins current with every edit:
`notes/Nursery 2 - {First,Second} Term.{md,docx}`. Third Term is tracked subject-by-subject in
**`75-THIRD-TERM.md`**, which also lists the traps already hit there.  The plate work still owed on
the two older books is kept in **`76-BACKFILL.md`**, generated by `tools/backfill_ledger.py` — run that
command, never edit the table.

**Resume the work in five commands** (all green takes about 25 s; run the same for the term you are in):

```bash
python3 tools/sheet_lint.py                                             # -> lines to re-balance: 0
python3 tools/polish_audit.py --class "Nursery 2" --term "2nd Term"     # -> 0 to fix
python3 tools/check_worksheets.py --class "Nursery 2" --term "2nd Term"
for f in data/exams/nursery-2__2nd-term__*.json; do
    python3 tools/make_exam.py "$f" --seed 0 --strict || echo "FAIL $f"; done
python3 tools/build_term_doc.py --class "Nursery 2" --term "2nd Term" --strict   # -> rule checks: all clear
python3 tools/book_pages.py --class "Nursery 2" --term "2nd Term"       # -> audit : CLEAN
```

`--strict` is the whole safety story: it refuses to build a book that overflows a page, that lists a
Contents line pointing at nothing, or whose printed page numbers disagree with the .docx it just wrote.

**Decisions the owner has already made — do not re-open, do not re-ask:**

* Layout stays **A4 landscape, two columns, Calibri 10.5**. No portrait or phone edition.
* The 13 practice papers **stay inside the book**; no separate paper files, no separate exam pack.
* Page flow stays **packed**: no one-lesson-per-page, no never-split-a-lesson rule.
* A **teacher's copy per term** is wanted — a separate, clearly named file with the keys and marking
  guidance. Not built yet: `60-ROADMAP.md` §1.
* **Polish is done** (2 Sep 2026): 90 draw/colour/cut/paste cues authored into the notes, 46 over-long
  lines split, 4 register words reworded, 1 repeated bullet fixed — report in
  `reports/polish-2026-09-02.md`. The Contents was deliberately **not** trimmed to parts-only, because
  the lesson-level page numbers were themselves the request.
* Order of work: polish → **Third Term** (this is the test of the plan on a new term) → then the next
  class, Primary 1 or Nursery 1 (still unnamed by the owner; `notes/README.txt` has said Primary 1).
* Pictures: **embedded in the book**; children drawn **fully, faces and hands included**; anything that
  fails inspection is **deleted in the same turn**. The **house style is colouring-book line art** — bold
  black outlines, no shading, no writing anywhere in the picture. The exact prompt prefix every image
  gets, the 1-bit PNG container rule, and the measured budgets are all in `50-IMAGES.md`.
  **The pipeline is built and in use (2 Sep 2026), and the pictures belong to the polishing, not to a later
  phase** — that was the owner's correction.  `tools/img_import.py` encodes a generation, files it, declares
  its pixels to `MANIFEST.jsonl`, deletes the raw, and writes the `![alt](path)` line into the note at the
  end of `**Let us talk**`; `book_layout` bills a plate at 193 pt before the Contents is numbered, and
  `--no-images` prints the text-only book.  Every note is now authored with its picture: 8 plates are in
  Second Term Basic Science (143 → 145 pages, `audit : CLEAN`), 2 in Third Term CCA;
  `assets/samples/` keeps the four options the owner compared and the style probe.
* The workspace-overload warning is taken seriously and measured: line art flattens to ~17 kB per image,
  so a class-term of 105 pictures costs **about 1.8 MB** (the coloured options would have cost 9.7–30.2 MB
  as JPEG). Raw generations cost 0.3–3 MB each and must never be left behind. Rules 6, 7 and 10 in
  `50-IMAGES.md` are the ones that keep this workspace alive.

**The rules that never bend** are in `10-BRIEF.md`. **Style** — how a note and an item must read — is
`20-STYLE.md`. **How the machinery works** is `30-ARCHITECTURE.md`. **Why it is built this way, and what
has already been tried and failed**, is `40-HISTORY.md`; read that before "fixing" anything that looks like
a bug, because several apparent bugs are deliberate. **Questions the owner still owes** are collected in
`70-OPEN-QUESTIONS.md`, with everything already answered in its top table — so a fresh session must not
re-ask them, and the answer picker in this workspace has dropped responses once, which is why that file exists.
