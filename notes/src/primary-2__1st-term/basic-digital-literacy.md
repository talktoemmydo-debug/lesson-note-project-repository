# Basic Digital Literacy — Primary 2 · First Term

These are the notes for the first term of Primary 2. They follow the NERDC
Basic Education Curriculum (2025 revision) and the school's scheme of work.
The eight weeks below are the weeks that carry a written note; the remaining
weeks of the term are for revision and the end-of-term paper, so no note is
written for them.

*Depth: NERDC Primary 2 · Basic Digital Literacy · First Term W1-5, 7-9 (the computer; computer hardware; computer software; uses of computers; the computer room; the keyboard; the mouse; care of the computer).*

---

### WEEK 1 — THE COMPUTER

**Main content**

• A **computer** is a machine that takes in information and gives out results.

• A computer can **work fast** and **store** information.

• The main parts of a computer are the **monitor**, **system unit**, **keyboard** and **mouse**.

• The **monitor** is the screen we look at.

• The **system unit** is the main box that does the work.

• The **keyboard** has keys we press.

• The **mouse** helps us point and click.

• A computer needs **electricity** to work.

• We use computers at school, home and offices.

• A computer is a useful machine.

**Let us talk**

1. What is a computer?

2. Name one part of a computer.

3. What does a computer need to work?

**Words for my notebook**

• computer — a machine that takes in information and gives results

• monitor — the screen of a computer

• system unit — the main box of a computer

**Worksheet**

1. A machine that takes in information and gives results is a ___.
   A) computer B) radio C) fan D) stove

2. The screen of a computer is the ___.
   A) monitor B) keyboard C) mouse D) speaker

3. The main box of a computer is the ___.
   A) system unit B) monitor C) mouse D) printer

4. A computer needs ___ to work.
   A) electricity B) water C) fire D) wind

5. Fill in: The part of a computer with keys we press is the _____.

6. Mention two parts of a computer.

7. Write what a computer is.

**My own work**

• Draw a computer and label its parts.

### WEEK 2 — COMPUTER HARDWARE

**Main content**

• **Hardware** is the parts of a computer we can **see and touch**.

• Examples of hardware: **monitor**, **keyboard**, **mouse**, **system unit**, **printer**.

• Some hardware are **input** devices — they put information in.

• The **keyboard** and **mouse** are input devices.

• Some hardware are **output** devices — they bring results out.

• The **monitor** and **printer** are output devices.

• The **system unit** holds the main working parts.

• Hardware can be damaged if we are not careful.

• We handle hardware with care.

• Hardware makes the computer work.

**Let us talk**

1. What is hardware?

2. Name one input device.

3. Name one output device.

**Words for my notebook**

• hardware — the parts of a computer we can see and touch

• input device — a device that puts information in

• output device — a device that brings results out

### WEEK 3 — COMPUTER SOFTWARE

**Main content**

• **Software** is the set of instructions that tell the computer what to do.

• We **cannot** touch software — it is not a physical part.

• Software makes the hardware work.

• There are two main types of software.

• **System software** helps the computer run (like the operating system).

• **Application software** helps us do work (like a drawing program).

• A **program** is a set of instructions.

• Without software, the hardware cannot do anything.

• We load software into the computer to use it.

• Software and hardware work together.

**Let us talk**

1. What is software?

2. Can we touch software?

3. Name one type of software.

**Words for my notebook**

• software — the instructions that tell the computer what to do

• program — a set of instructions

• system software — software that helps the computer run

**Worksheet**

1. The instructions that tell the computer what to do are ___.
   A) software B) hardware C) wires D) keys

2. Can we touch software?
   A) no B) yes C) maybe D) sometimes

3. Software that helps us do work is ___ software.
   A) application B) system C) hard D) soft

4. Without software, the hardware ___.
   A) cannot do anything B) works faster C) sings D) sleeps

5. Fill in: A set of instructions is a _____.

6. Mention two types of software.

7. Write what software is.

**My own work**

• Draw a computer and write one thing software does.

### WEEK 4 — USES OF COMPUTERS

**Main content**

• Computers are used in many places.

• At **school**, we use computers to **learn** and **type**.

• At **home**, we use computers to **play**, **draw** and **watch**.

• In **offices**, computers help to **write** and **keep records**.

• In **hospitals**, computers help doctors.

• In **banks**, computers keep money records.

• We can **draw**, **write** and **calculate** with a computer.

• Computers help us **store** information.

• Computers make work **fast** and **easy**.

• We use computers with care.

**Let us talk**

### WEEK 5 — THE COMPUTER ROOM

**Main content**

• The **computer room** is where we use computers at school.

• We enter the computer room with **permission**.

• We **do not eat or drink** in the computer room.

• We handle the computers with **care**.

• We do not press keys **hard** or roughly.

• We keep the computer room **clean**.

• We do not make **noise** in the computer room.

• We follow the teacher's **instructions**.

• We do not touch wires or plugs.

• Good behaviour keeps the computers safe.

### WEEK 7 — THE KEYBOARD

**Main content**

• The **keyboard** is an input device with keys.

• We use the keyboard to **type** into the computer.

• The keyboard has **letter keys** (A to Z).

• The keyboard has **number keys** (0 to 9).

• The **space bar** makes a space between words.

• The **enter key** starts a new line.

• The **shift key** helps us type capital letters.

• The **backspace key** removes a letter.

• We press the keys **gently**.

• The keyboard helps us write on the computer.

### WEEK 8 — THE MOUSE

**Main content**

• The **mouse** is an input device.

• We use the mouse to **point** at things on the screen.

• The mouse has **buttons** (left and right).

• We **click** by pressing a button once.

• We **double-click** by pressing twice quickly.

• We **drag** by holding the button and moving.

• The mouse moves the **pointer** on the screen.

• Some mice have a **wheel** to scroll.

• We handle the mouse with care.

• The mouse helps us work on the computer.

**Let us talk**

1. What is the mouse?

2. What does clicking do?

3. How do we handle the mouse?

**Words for my notebook**

• mouse — the input device we use to point

• click — to press a mouse button once

• pointer — the arrow on the screen

### WEEK 9 — CARE OF THE COMPUTER

**Main content**

• We care for the computer so it lasts long.

• We keep the computer **clean** and free of dust.

• We do not eat or drink **near** the computer.

• We handle the parts with **care**.

• We do not press keys **hard**.

• We keep the computer away from **water**.

• We switch it off **properly** when we finish.

• We keep the **wires** and plugs safe and dry.

• We cover the computer when not in use.

• Good care keeps the computer working well.

**Let us talk**

1. Why do we care for the computer?

2. Name one way to care for it.

3. When do we switch it off?

**Words for my notebook**

• care — to look after something well

• dust — fine dry powder

• switch off — to turn off

**Worksheet**

   A) properly B) quickly C) roughly D) never
